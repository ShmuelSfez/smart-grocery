🔒 נדרשת הרשאת גישה לגיליון

כדי שהאתר יוכל לקרוא את רשימת הקניות מתוך הקישור של Google Sheets, הגיליון צריך הרשאת צפייה בקישור.

  1. לחץ על פתח את הגיליון להרשאה למטה.
  2. בפינה הימנית-עליונה בגיליון לחץ Share (שיתוף).
  3. תחת General access שנה מ-Restricted ל-Anyone with the link (Viewer / צפייה).
  4. חזור לכאן ולחץ שיניתי, טען עכשיו ↻.

🧩 התקנת התוסף לכרום (תומך בשופרסל ורמי לוי)

  1. הורד את קובץ התוסף (shufersal-extension.zip) וחלץ אותו לתיקייה במחשב.
  2. פתח בכרום את הכתובת chrome://extensions והפעל Developer mode (למעלה מימין).
  3. לחץ Load unpacked ובחר את התיקייה שחילצת (או לחץ ↻ אם כבר מותקן).
